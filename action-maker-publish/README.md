# アクションメーカー

キャラ画像とモノ画像を置いて、往復・回転・のび縮み・歪み（タッチ／膨らみ凹み／螺旋）とマスク領域で動かす、ブラウザ用の小さなアニメ作成ツールです。背景の変更、ペン・文字、録画（動画）・GIF・高解像度PNG/JPEG書き出し、作品の保存・読み込み、元に戻す、サンプル付きです。
画像はすべて端末内で処理され、外部には送信されません。

## 公開のしかた（GitHub Pages・無料）
1. GitHubでリポジトリを作り、このフォルダの中身をすべてアップロードします。
2. Settings → Pages → Branch を `main` / `(root)` にして保存します。
3. 表示されたURLを開くと使えます。スマホでは「ホーム画面に追加」で、オフラインでも動くアプリとして使えます。
   （Cloudflare Pages / Netlify にフォルダをドラッグ&ドロップする方法でも同じです）

## 更新のしかた
- `index.html` を差し替え、`sw.js` の `VERSION` を上げてアップロードします（利用者の端末のキャッシュが更新されます）。
- 変更履歴はGitのコミット、公開版の区切りはタグ（v3.0.0 など）で管理できます。

## 公開前に決めておくこと
- ライセンス（MIT / 非公開など）。まだ決めていない場合は `LICENSE` を置くまで「All rights reserved」扱いになります。
- 名前。似た名前の既存アプリと紛らわしくないか確認してください。
- プライバシー：画像は端末内で処理し送信しない、と一文書いておくと安心です。
- 絵文字は各端末の標準フォントで表示されます。画像を使う場合は権利に注意してください。
